# Football Association Rule Mining

Projeto de **Mineração de Dados utilizando Regras de Associação** desenvolvido em Python e executado no Google Colab.

O projeto utiliza o algoritmo **Apriori** para identificar padrões entre estatísticas de desempenho de jogadores de futebol e o sentimento dos comentários publicados por torcedores nas redes sociais.

Esta análise faz parte do meu **Trabalho de Conclusão de Curso (TCC)**, que investigou a relação entre o desempenho esportivo de jogadores de futebol e a percepção dos torcedores nas redes sociais.

---

## 🎯 Objetivo do projeto

O objetivo desta etapa do projeto foi aplicar técnicas de **mineração de dados por regras de associação** sobre uma base contendo métricas de desempenho esportivo e índices de sentimento.

A análise busca encontrar padrões no formato:

**Estatísticas de desempenho → Índice de Sentimento**
